in this tasks we will update leads statuses and behaviour 
in http://localhost:4200/dashboard/overview/leads page
we need to define actions to do for each lead, the action trigger will be the status change for leads

- 'Visite à planifier' : opens a popup that have a date/time selects and a confirm button (UI like in the frontend\src\app\dashboard\visits\visit-detail.component.html page), confirming will delete the lead document and create a visit request document, after the operation is done redirect use to the http://localhost:4200/dashboard/overview/visits/justCreatedVisitId
- 'A Contacté' : open a popup with a note edit and a confirm button, confirming will just save the note/status in the lead document
- 'Offre effectuée' : opens a popup with price input field and a confirm button, confirming will save price/status in the lead document
- 'Offre rejeté' : updates directly the lead status
- 'Demande' : open a confirm popup saying transform this to a demand ? with a confirm button, confirming will delete the lead document and create a demand documment, after the operation redirect user to http://localhost:4200/dashboard/demands/justCreatedDemandId

the lead default status should be 'Prospect' (client non contactée)
popup should be moibile friendly !
