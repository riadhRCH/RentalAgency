PIPELINE / KANBAN VIEW — "Entonnoir"

Overview:
  Implement a Kanban-style board showing clients organized by sales pipeline stage with visual progress tracking.

Columns/Stages:
  - Prospect — New leads not yet contacted 
  - Visite à planifier — Clients ready to schedule a property visit 

Client Cards Display:
  - Full name
  - Email address
  - Phone number (when available)
  - Budget range (color-coded badge)
  - Purchase type badge (e.g., "Paiement comptant" = cash payment)
  - Assigned agent (avatar + name)

Progress Indicator:
  - Donut chart showing total client count
  - Color-coded by stage (grey = Prospect, blue = Visite à planifier)

Acceptance Criteria:
  ✓ Kanban board renders pipeline stages as columns
  ✓ Client cards display all required fields with proper badges
  ✓ Cards are draggable between pipeline stages
  ✓ Stage change persists to backend on drop
  ✓ Donut chart updates in real-time when clients move between stages
  ✓ Budget range is color-coded based on value
  ✓ Agent avatar + name displayed on card
  ✓ Responsive layout (stacks vertically on mobile)

Technical Notes:
  - Build Angular standalone component for Kanban board
  - Use CSS Grid or Flexbox for column layout
  - Implement drag-and-drop (Angular CDK DragDrop or similar)
  - POST/PATCH endpoint to update client pipeline stage
  - Donut chart via chart library (Chart.js, ngx-charts, or SVG)
  - Color mapping config for budget ranges and stages
  - Filter clients by agencyId and stage

Priority: High
Dependencies: Client module (backend), Auth module
