PROPERTY VISIT REQUEST FORM — "Formulaire de demande de visite"

Overview:
  Create a public-facing form for clients to request a property visit. When submitted, a new client record is created in the CRM.

Header Message:
  "Merci pour votre intérêt pour nos propriétés. L'un de nos agents reviendra vers vous sous 24h."

Form Fields:
  - Nom (required) — Full name
  - Téléphone (required) — Phone number
  - E-mail (required) — Email address
  - Moyen de contact favori (required) — Radio: Téléphone / E-mail / SMS message
  - Les propriétés qui vous intéressent (required) — Checkbox list of available properties (multi-select)
  - Disponibilité (required) — Open text field for availability over the next 3–4 days
  - Type d'achat — Radio: Paiement comptant / Emprunt
  - Budget — Radio with ranges: 100K–120K / 120K–150K / 150K–200K / 200K–250K / 250K–300K €

Acceptance Criteria:
  ✓ Form is publicly accessible (no auth required)
  ✓ Header message displayed prominently at top
  ✓ All required fields validated before submission
  ✓ Properties list populated from backend (active properties only)
  ✓ On submit, creates a new client record with Statut = "Visite à planifier"
  ✓ Confirmation message shown after successful submission
  ✓ Responsive design for mobile and desktop
  ✓ Rate limiting to prevent spam submissions

Technical Notes:
  - Build Angular standalone component (no auth guard)
  - Reactive forms with Validators for required fields
  - GET /properties/active endpoint to populate property checkboxes
  - POST /clients/public endpoint (no JWT required, rate-limited)
  - Auto-assign default agent or unassigned on creation
  - Add rate limiting middleware (e.g., express-rate-limit)
  - Success/error toast notifications

Priority: High
Dependencies: Client module, Properties module, Rate limiting middleware
