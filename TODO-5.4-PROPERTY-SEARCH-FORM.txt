PROPERTY SEARCH REQUEST FORM — "Formulaire de demande de biens"

Overview:
  Create a form for clients to describe what they're looking for, so agents can alert them when a matching property becomes available.

Header Message:
  "Faites nous part de ce que vous recherchez et nous vous enverrons un e-mail si quelque chose susceptible de vous intéresser se présente."

Restriction:
  Only accessible to workspace members ("Only members at Espace de Doghmani Homes can fill out this form").

Form Fields:
  - Nom (required) — Full name
  - E-mail (required) — Email address
  - Nombre de chambres (required) — Multi-select (Studio / Une / Deux / Trois / Quatre ou plus)
  - Zones (required) — Multi-select geographic preferences
  - Caractéristiques indispensables — Multi-select optional must-haves (Garage, Piscine, Jardin, Balcon)
  - Autres détails importants — Free-text notes
  - Budget (required) — Budget range

Acceptance Criteria:
  ✓ Form requires workspace member authentication
  ✓ All required fields validated
  ✓ Multi-select fields use checkbox groups or tag input
  ✓ On submit, creates a client record with Statut = "Prospect"
  ✓ Stores search criteria for property matching/alerting
  ✓ Confirmation message shown after successful submission
  ✓ Responsive design

Technical Notes:
  - Build Angular standalone component with auth guard (workspace members only)
  - Reactive forms with multi-select controls
  - POST /clients/public/search endpoint (JWT required, member role)
  - Store search criteria as structured data on client record for later matching
  - Future: implement email alert when new property matches stored criteria
  - Nodemailer integration for alert emails (future iteration)

Priority: Medium
Dependencies: Client module, Auth module (member role), Nodemailer
