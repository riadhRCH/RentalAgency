CONFIGURATION DATA & BADGE SYSTEM

Overview:
  Implement all dropdown/select options and a badge/chip display system for the CRM. These values are used across the pipeline, client list, forms, and client records.

Zones:
  Zone nord, Zone est, Zone ouest, Zone sud, Extension sud, Près du lac

Budget Ranges:
  100 000–120 000 €, 120 000–150 000 €, 150 000–200 000 €, 200 000–250 000 €, 250 000–300 000 €

Caractéristiques indispensables (Must-have features):
  Garage pour 1 voiture, Garage pour 2 voitures, Piscine, Jardin, Balcon / terrasse

Nombre de chambres (Bedrooms):
  Studio, Une, Deux, Trois, Quatre ou plus

Type d'achat (Purchase type):
  Paiement comptant, Emprunt

Moyen de contact favori (Preferred contact):
  Téléphone, E-mail, SMS / message

Badge System:
  - Color-coded badges for budget ranges (green for lower, yellow for mid, red for high)
  - Status badges: Prospect (grey), Visite à planifier (blue)
  - Purchase type badges with distinct styling
  - Chip/tag display for multi-select values (zones, features, bedrooms)

Acceptance Criteria:
  ✓ All dropdown options configurable from a central source (enum or DB)
  ✓ Badges render consistently across pipeline, list, and client profile
  ✓ Multi-select values display as removable chips in forms and detail views
  ✓ Color coding applied correctly by value type
  ✓ New options can be added without code changes (admin-configurable)
  ✓ Translation-ready (French labels)

Technical Notes:
  - Define enums or a configuration collection in MongoDB for all option lists
  - Create a shared Angular config service to fetch dropdown options
  - Build reusable BadgeComponent and ChipListComponent
  - Color mapping utility function for budget ranges
  - Optional: admin page to manage dropdown values at runtime
  - Store selected values as strings (enum keys or IDs) on client records
  - Cache config data in frontend to avoid repeated API calls

Priority: Medium
Dependencies: Client module, Admin config module (optional)
